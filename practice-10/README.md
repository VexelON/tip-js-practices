## 5. Контрольные вопросы

1. Форму можно обойти, сервер проверяет сам.
2. Иначе возможна частичная запись.
3. PATCH без поля сохраняет прежнее значение.
4. `if (completed)` пропустит `false`.
5. Длина массива не монотонна после удалений.
6. `__proto__` не должен ломать словарь ошибок.
7. 415 — неверный тип, 400 INVALID_JSON — синтаксис.
8. Сначала id/существование, затем тело.
9. Между GET и UPDATE запись могли удалить.
10. Браузер должен прочитать Location.
11. Reset уничтожает учебные данные без авторизации.
12. Ошибка GET после POST не отменяет создание.
13. Повтор POST может дать дубликат.
14. Память процесса живёт, пока жив Node.
15. Следующий шаг — постоянное хранение в PostgreSQL.
