## 2. Builders и store

`buildListTasksQuery` экранирует `%` `_` `\` и ставит `ESCAPE`. `reset` использует один `client`: BEGIN → DELETE → INSERT seed → setval → COMMIT, в `finally` release.

SQLSTATE `23503` → 400, класс `08`/`57P01` → 503. В ответ не попадают пароль, SQL и `detail`.

## 3. Вариант 6

`q=%_` ищется как текст, не как два wildcard. Создание названия с буквальными `%_` затем поиск `%_` находит запись.

## 4. Проверки

Фактический вывод `npm test` фиксируется командой ниже. Без `DATABASE_URL` live-тест помечен skipped.

## 5. Контрольные вопросы

1. Pool переиспользует соединения.
2. Значения только в `$n`, не в тексте SQL.
3. Имена колонок нельзя параметризовать.
4. AS "categoryId" сохраняет регистр.
5. LIKE считает `%` шаблоном.
6. ESCAPE отключает спецсимволы в образце.
7. Identity назначает id без max+1.
8. RETURNING избавляет от второго SELECT.
9. Пустой UPDATE — 404, не 200 null.
10. pool.query('BEGIN') не держит то же соединение.
11. Sequence не откатывается.
12. SQLSTATE стабильнее текста.
13. Reset без авторизации опасен.
14. Клиент ПР8 меняет только URL.
15. Секрет только в `.env`.
