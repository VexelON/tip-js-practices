# Что сделать вручную

1. Вписать имя и группу в корневой `README.md` и отчёты практик.
2. ПР1: скриншот точки останова; ПР1/ПР3/ПР5: наблюдения DevTools.
3. Установить PostgreSQL 18, задать пароль роли `tip_app` только в локальном `.env` (`practice-12`/`practice-14`), выполнить SQL ПР11.
4. Node.js 24 LTS, Docker Desktop, GitHub: создать пустой репозиторий, `git push -u origin main`, `git push origin v1.0.0`, проверить Actions.
5. Если номер варианта по журналу не 6, сменить `variant.js` / SQL варианта / счётчик запросов ПР14.
