# Эксплуатация

- Конфигурация только через переменные окружения. `DATABASE_URL` не кладётся в образ.
- Liveness: процесс принимает HTTP. Readiness: ping базы и флаг приёма запросов.
- SIGTERM: сервер перестаёт принимать соединения, ждёт обнуления счётчика активных запросов в пределах `SHUTDOWN_TIMEOUT_MS`, затем закрывает пул.
- `ENABLE_DEBUG_RESET` в продакшене `false`.
